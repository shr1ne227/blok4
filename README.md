## Запуск в IntelliJ IDEA

1. Откройте папку `blok4` как отдельный проект.
2. Выберите установленный JDK в настройках проекта, если IDE попросит его указать.
3. В списке конфигураций раскройте нужную папку **«Практика 18»**, **«Практика 19»**, **«Практика 20»** или **«Практика 21»**.
4. Выберите задание и нажмите **Run ▶**. Также можно запустить метод `main` класса из таблицы.

## Что вводить при проверке

| Программа | Пример проверки |
| --- | --- |
| `Exception2`, `Exception3`, `Exception4` | Введите `1`, `0`, `1.2` или `Qwerty`. Для каждого значения запустите программу заново. |
| `OnlineShop` | Введите ФИО и ИНН из учебной базы, которая выводится при запуске. Затем повторите запуск с неверными данными. |
| `LabClassDriver` | `1` — список, `2` — сортировка по убыванию балла, `3` — поиск по полному ФИО, `0` — выход. |
| `DirectoryList` | Введите `.` для текущей папки проекта или путь к другому каталогу. |

Остальные программы используют примеры данных, заданные в коде, и сразу выводят результат.

## Запуск из терминала

В корне проекта скомпилируйте исходные файлы:

```sh
javac -encoding UTF-8 -d out src/practice*/task*/*.java
```

Затем запустите нужный класс, например меню студентов:

```sh
java -cp out practice19.task2.LabClassDriver
```

Для другого задания используйте его пакет и имя класса из таблицы, например `practice21.task4.DirectoryList`.

## Особенности

- Проверка ИНН выполняется по учебным записям, которые показаны в программе.
- Методы `Calculator` возвращают результат типа `double`; деление на ноль обрабатывается исключением.
- При чтении каталога выводятся первые пять имён в порядке файловой системы. Если элементов меньше пяти, выводятся все.
- Скомпилированные файлы в папке `out` исключены из Git.
