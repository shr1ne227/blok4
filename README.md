# АиСД · Блок 4

Практические работы по дисциплине «Введение в алгоритмы и структуры данных систем реального времени».

**РТУ МИРЭА · КВБО-11-25 · Дубовецкий А. Х.**

## Задания

| Работа | Что реализовано | Точка входа |
| --- | --- | --- |
| [Практика 18](src/practice18) | Четыре примера обработки исключений: деление на ноль, ошибки ввода, порядок `catch` и блок `finally`. | `Exception1`–`Exception4` |
| [Практика 19](src/practice19) | Проверка ФИО и ИНН по учебной базе. Поиск и сортировка студентов с собственными исключениями. | [OnlineShop.java](src/practice19/task1/OnlineShop.java), [LabClassDriver.java](src/practice19/task2/LabClassDriver.java) |
| [Практика 20](src/practice20) | Обобщённый класс с тремя параметрами типа, поиск минимума и максимума, калькулятор. | [TripleTest.java](src/practice20/task1_3/TripleTest.java), [MinMaxCalculatorTest.java](src/practice20/task4/MinMaxCalculatorTest.java) |
| [Практика 21](src/practice21) | Преобразование массива в список, хранение массивов, доступ по индексу и чтение каталога. | Классы с `main` в `task1`–`task4` |

## Запуск в IntelliJ IDEA

1. Откройте корневую папку проекта `blok4` и выберите установленный JDK в настройках проекта.
2. В списке конфигураций выберите задание из папки **«Практика 18»**, **«Практика 19»**, **«Практика 20»** или **«Практика 21»** и запустите программу.

## Запуск из терминала

В корне проекта скомпилируйте задания.

```sh
javac -encoding UTF-8 -d out src/practice*/task*/*.java
```

Запустите нужный класс, например меню студентов или чтение каталога.

```sh
java -cp out practice19.task2.LabClassDriver
java -cp out practice21.task4.DirectoryList
```
